# Solicitation Notice: Federal IT Infrastructure Modernization and Cloud Migration
**Agency:** General Services Administration (GSA), Federal Acquisition Service  
**Date:** 2026-03-22  
**Document Type:** tender  
**Solicitation Number:** GSA-ITM-2026-9041  

## 1. Description of Requirement
The General Services Administration issues this competitive public tender for comprehensive information technology modernization services across federal civilian branch agencies. The objective is to replace legacy on-premises mainframe and client-server systems with secure, multi-tenant cloud native solutions.

## 2. Scope of Work
- **Work Package 1: Automated Data Migration:** Ingestion, validation, and schema transformation of approximately 45 terabytes of unstructured document archives, PDF notices, and regulatory filings into searchable distributed object stores.
- **Work Package 2: High-Performance Search and Retrieval Engine:** Deployment of full-text search engine clusters providing sub-millisecond keyword, phrase, and Boolean query retrieval over indexed government repositories.
- **Work Package 3: Zero-Trust Identity Federation:** Implementation of FedRAMP High compliant authentication mechanisms, role-based access control, and encrypted transport layer security.

## 3. Submission Guidelines and Evaluation Criteria
Proposals will be evaluated based on technical merit (40%), past performance on federal cloud modernization projects (30%), and total evaluated price (30%). All bidding contractors must hold active facility security clearances and submit bids prior to the closing date.
